# Homebrew tap for Istok

[Istok](https://istok.sh) keeps the tasks, runs and checks of your coding agent on your machine.

```sh
brew install vtimame/tap/istok
```

Update with `brew upgrade istok`. The formula is published by the release workflow of [vtimame/istok.sh](https://github.com/vtimame/istok.sh) for every release; do not edit it here.

Istok runs on macOS (Intel, Apple Silicon) and Linux (x86-64, ARM64, glibc 2.34 or newer).
